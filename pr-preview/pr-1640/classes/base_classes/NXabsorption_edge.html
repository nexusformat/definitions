3.3.1.13. NXabsorption_edge¶

Status:

base class, extends NXobject

Description:

An X-ray absorption edge. …

An X-ray absorption edge.

An absorption edge is a sharp discontinuity in the X-ray absorption spectrum of an atom that occurs when the incident photon energy reaches the threshold energy for exciting the atom to a state with a core vacancy. The threshold energy is characteristic of the element and can depend on the chemical state of the atom.
