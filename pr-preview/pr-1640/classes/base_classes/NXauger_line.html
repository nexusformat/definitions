3.3.1.26. NXauger_line¶

Status:

base class, extends NXobject

Description:

An Auger line. …

An Auger line.

An Auger line comes from the non-radiative decay of a level with a core vacancy. A less tightly bound electron fills the vacancy and the atom emits a second electron, the Auger electron. The kinetic energy of the Auger electron is characteristic of the element and can depend on the chemical state of the atom.

Symbols:

No symbol table

Groups cited:

NXelement

Structure:

name: (optional) NX_CHAR

Name of the Auger line. …

Name of the Auger line.

The IUPAC notation has the form INITIAL-FINAL1FINAL2. INITIAL identifies the initial level. FINAL1FINAL2 identifies the final level, which contains two vacancies. For example, K-L1L2 denotes a transition from the K level to the L1L2 level, with vacancies in L1 and L2.
