3.3.3.102. NXxas_trans¶

Status:

application definition (contribution), extends NXxas

Description:

In transmission, the linear attenuation coefficient or absorption …

In transmission, the linear attenuation coefficient or absorption coefficient \(\mu(E)\) is given by the Beer-Lambert law:

\[\mu(E)t = -\ln(I/I_0)\]

where \(I\) is the intensity of the transmitted beam, \(I_0\) is the intensity of the incident beam, and \(t\) is the thickness of the sample.

The top-level intensity field contains the processed absorbance. When the raw detector data and processing steps are available, they can be stored in the recommended NXinstrument group and the optional NXcollection and NXprocess groups, enabling full reproducibility of the data reduction.

The absorbance \(\mu(E)t = -\ln(I/I_0)\), the product of …

The absorbance \(\mu(E)t = -\ln(I/I_0)\), the product of the absorption coefficient \(\mu(E)\) and the sample thickness \(t\).

INSTRUMENT: (recommended) NXinstrument ⤆

The data field of each detector below holds the intensity …

The data field of each detector below holds the intensity used to compute the absorbance and may already include corrections. If the uncorrected values are kept, they are archived in the NXcollection group and the corrections are described in NXprocess.

Detector measuring the reference intensity …

Detector measuring the reference intensity \(I_{ref}\), placed after a reference sample (typically a metal foil). Provide this detector when the reference is a simultaneous transmission channel that shares the main energy axis. For a reference that is an independent spectrum, in particular one probing a different absorbing element or absorption edge, use the reference subentry instead. Do not provide both for the same reference.
