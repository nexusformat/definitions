=====
NXxas
=====

**Status**:

  *application definition* (contribution), extends :ref:`NXobject`

**Description**:

  .. collapse:: This is a generic application definition for X-ray absorption ...

      This is a generic application definition for X-ray absorption
      spectroscopy. Technique-specific application definitions extend this base
      definition.

**Symbols**:

  .. collapse:: The symbol(s) listed here will be used below to coordinate datasets ...

      The symbol(s) listed here will be used below to coordinate datasets
      with the same shape.

  **nP**: Number of spectra (scan points). For a stack, this is the growable first dimension of ``intensity``: data could be appended along it during acquisition. For a single spectrum, ``nP`` is 1, but ``intensity`` has no ``nP`` dimension.

  **nEnergy**: Number of energy data points

  **dataRank**: Rank of the ``intensity`` field: 1 for a single spectrum ``[nEnergy]`` or 2 for a stack of spectra ``[nP, nEnergy]``.

    **DATA**: (required) :ref:`NXdata` :ref:`⤆ </NXentry/DATA-group>`

      .. collapse:: Plot of the X-ray absorption ``intensity`` versus ``energy``. ...

          Plot of the X-ray absorption ``intensity`` versus ``energy``.
          The ``energy`` and ``intensity`` links are required. Additional
          coordinate links are allowed.

          For a single spectrum, ``energy`` spans dimension 0
          (``@energy_indices = 0``). For a stack, ``energy`` has
          ``@energy_indices = 1`` and the quantity that varies across the
          stack (a time series, a spatial map, an operando series, ...)
          is the leading axis with ``@AXISNAME_indices = 0``.

          That quantity is stored in its standard NeXus location (for
          example ``NXsample/temperature``, ``NXsample/electric_field``,
          an ``NXsample/NXtransformations`` axis, or an ``NXbeam``
          polarization field) and linked here. The application definition
          does not enumerate these coordinates: any of them, including
          ones not listed, is declared by adding the field in its
          base-class location and wiring it into this group.
