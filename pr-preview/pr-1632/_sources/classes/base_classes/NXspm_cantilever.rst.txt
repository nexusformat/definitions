================
NXspm_cantilever
================

**Status**:

  base class, extends :ref:`NXcomponent`

**Description**:

  .. collapse:: A base class to describe the cantilever used in Atomic Force Microscopy (AFM). ...

      A base class to describe the cantilever used in Atomic Force Microscopy (AFM).

      The cantilever defines the probe frame: origin at the tip apex, ``x`` along the projection
      of the cantilever long axis (from the tip towards the chip), ``z`` along the tip axis
      (from the apex towards the cantilever), and ``y`` = ``z`` × ``x``, the torsion-sensing
      direction. Its orientation is given by ``depends_on`` and ``transformations``.
